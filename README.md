Task 5: Titanic Exploratory Data Analysis (EDA)

Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand passenger characteristics, data quality, and survival patterns using Python.

Objectives

- Understand the dataset structure and summary statistics.
- Identify missing values and duplicate records.
- Analyze survival rates by sex and passenger class.
- Visualize age and fare distributions.
- Explore correlations between numerical variables.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

Files Included

- "train.csv" – Original Titanic dataset.
- "Task_5_Titanic_EDA_Report.pdf" – EDA report and visualizations.
- "Task_5_Titanic_EDA_Python_Code.pdf" – Python code reference.
- "Task_5_Titanic_EDA_Notebook_in_PDF.pdf" – Notebook-style code and outputs.

Key Findings

- Approximately 38.4% of passengers survived.
- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than third-class passengers.
- The dataset contains missing values, particularly in the Age and Cabin columns.

Conclusion

The analysis highlights important patterns in passenger survival and demonstrates how data exploration and visualization can generate meaningful insights.

Note: The notebook-style PDF is a reference document, not an executable ".ipynb" file.
